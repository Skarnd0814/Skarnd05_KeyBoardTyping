# 🎈 키보드 타이핑 타이쿤 (Keyboard Typing Tycoon)

> 문구를 정확하게 쳐서 다트를 던지고, 떠오르는 풍선을 터뜨려 골드를 모으는 타이핑 타이쿤 게임

Unity로 만든 2D 캐주얼 타이핑 게임입니다.
따뜻한 나무 분위기 속에서 속담과 단어를 치며 풍선을 터뜨리고, 강화·보스·환생을 거치며 점점 더 빠르고 화려하게 성장합니다.

## 🎮 게임 방법

1. 화면 아래 타이핑 칸에 보이는 문구를 똑같이 입력하고 **Enter**를 누릅니다.
2. 정확히 입력하면 다트가 날아가 떠오르는 풍선을 터뜨립니다. 틀리면 다음 문구로 넘어갑니다.
3. 풍선에서 나온 골드로 강화를 사서 더 많은 풍선을 더 빠르게 터뜨립니다.
4. 풍선을 충분히 터뜨리면 **환생**에 도전할 수 있습니다. 계속 커지는 보스 풍선을 타이핑으로 줄여 격파하면 SP를 얻고, 스킬 트리에서 영구 능력을 배운 뒤 새 판을 시작합니다.

## ✨ 주요 기능

- **타이핑 → 다트**: 한글은 자모 단위로 타수를 세어 CPM을 계산하고, CPM이 높을수록 풍선이 터지는 이펙트가 커집니다.
- **다양한 풍선**: 골드가 다른 6종 풍선과 황금·단단한·분열 특수 풍선. 작은 풍선일수록 맞히기 어렵습니다.
- **강화**: 골드 획득량, 다트 속도·정확도, 풍선 생성 시간·개수·상승 속도, 한 번에 던지는 다트 수, 자동 다트, 보너스 문구 등
- **보스와 환생**: 보스를 격파하면 SP를 얻고 새 판을 시작합니다. 많이 터뜨릴수록 보스는 어렵지만 SP를 더 줍니다.
- **스킬 트리**: 네 갈래 스킬에서 풍선 관통·풍선 폭발·유도 다트·자동 타이핑 같은 특수 능력을 열 수 있고, 언제든 초기화해 다시 투자할 수 있습니다.
- **자동 타이핑**: 문구가 한 타씩 자동으로 쳐지는 모습과 키보드 소리 (최대 960 CPM), 켜기/끄기 스위치
- **트레일 뽑기**: 풍선을 터뜨려 모은 재화로 다트 꼬리(트레일) 17종을 뽑고 착용합니다.
- **한국어 / English**: 설정에서 언어를 바꾸면 화면 글자와 타이핑 문구가 함께 바뀝니다.
- **자동 저장**: 진행 상황과 언어·음량 설정이 저장됩니다.

## ⌨️ 조작

| 입력 | 동작 |
|---|---|
| 문구 입력 + Enter | 다트 던지기 |
| 마우스 클릭 | 강화 구매, 버튼 누르기 |
| 마우스 휠 | 강화 목록 스크롤 |
| Esc | 설정 창 열기 / 닫기 |

## 🛠️ 개발 환경

- Unity 6 (6000.3.25f1), URP 2D
- C#, TextMeshPro, Input System

## ▶️ 실행 방법

1. Unity Hub에서 이 프로젝트를 Unity 6000.3.25f1로 엽니다.
2. 메뉴에서 **Tools > Typing Tycoon > 메인 씬 구성하기**를 실행합니다.
3. `Assets/Scenes/Main.unity`를 열고 Play를 누릅니다.
